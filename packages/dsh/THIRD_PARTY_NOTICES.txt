e-Mate includes the DeepSeek Harness 0.1.5-rc.1 runtime assembled
from downstream commit 43c411a51c555e61e9b5f500442cb3404a2d70cd, based on upstream commit
183f08e9c6dde7e36cd2318eaee70b0da08fb35e, with the accepted bounded prompt,
redundant-permission, session draft and attachment isolation, bounded and
cleared Composer notice, native Computer Use mention identity, and current-Turn
turn-tail node-currency boundaries.
Each redistributed Harness package keeps its own LICENSE file under
runtime/harness/node_modules.

- yaml 2.9.0 — ISC
