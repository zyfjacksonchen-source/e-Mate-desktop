# 中文商务文档设计

新建报告默认 A4、上下页边距 22 mm、左右 23 mm。正文 10.5–11 pt、行距 1.35、段后 6 pt；标题 22 pt，一级标题 16 pt、二级标题 12 pt。标题与下段保持同页，避免孤立标题。正文深灰、辅助说明灰色，只用一种低饱和强调色（例如深蓝 214E70 或品牌橙 B94B0B）。表格保持淡色表头、清晰对齐，避免整页密集网格。

在 `styles` 中更新 Normal、Title、Heading 1、Heading 2，而不是给每段直接套格式。`font` 设置西文字体，`east_asia_font` 设置实际可用的中文字体；优先使用宿主可验证的 Noto Sans CJK SC 或平台已安装字体。声明字体名称不代表字体已安装或嵌入。可设置 `space_before_pt`、`space_after_pt`、`line_spacing`、`keep_with_next`。示例：

```json
{"name":"Normal","font":"Arial","east_asia_font":"Noto Sans CJK SC","size_pt":11,"color":"24292F","space_after_pt":6,"line_spacing":1.35}
```

短报告先摘要和关键结论，再展开证据、表格与行动项；合同或信函遵守用户现有结构，不擅自改变专业内容。用户提供模板时沿用模板层级、配色、页眉页脚及版式，仅修改授权内容。默认另存副本；跨 run 替换继承匹配开始处格式，其他字符格式保留。`set-cell` 会清除单元格内格式，保格式需求用定向 run 替换，不能宣称它保留样式。

创建后重新读取并核对文本与结构。Word/PDF 美观验收必须通过实际渲染逐页检查：无裁切、表格溢出、字体缺字、孤行、空白末页；不存在渲染器时明确仍未完成视觉验收，不能用 DOCX 包检查代替。优先复用既有宿主渲染能力，不安装另一套 Agent。
