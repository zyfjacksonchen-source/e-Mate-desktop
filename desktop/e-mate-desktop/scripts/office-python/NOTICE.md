# Office Python dependencies

These requirements are fixed official PyPI wheels for the existing CPython 3.12.14 bootstrap. Each URL has a SHA-256 digest; installation uses binary wheels, no dependency resolution, and a staging directory. Package metadata, exact versions and license-file names are recorded in `manifest.json`. Preserve all wheel `dist-info` licenses and the PDFium dependency license directories in distributed runtime bytes.

The selected pypdfium2 5.11.0 supports the product's existing macOS 12 minimum on both architectures. 5.12.1 and 5.13.0 require macOS 13; 5.12.0 has no usable Mac wheels. cryptography 48.0.1 preserves the Mac x64 wheel path absent from 50.0.1. These choices do not raise the application's minimum OS requirement. Runtime tests remain necessary; metadata compatibility is not execution evidence.

Top-level dependencies are reportlab 4.4.9 (BSD), pypdf 6.10.0 (BSD-3-Clause), pdfplumber 0.11.9 (MIT), openpyxl 3.1.5 (MIT), Pillow 12.3.0 (MIT-CMU), and pypdfium2 5.11.0 (BSD-3-Clause / Apache-2.0 and bundled dependency licenses). Transitive notices remain in the original distributions. PDFium includes additional component notices and CC-BY-4.0 material; do not replace those directories with only the wrapper's BSD notice.

ReportLab also includes separately licensed fonts under `reportlab/fonts`. Preserve the Bitstream Vera license and the complete DarkGarden material: `DarkGarden.sfd` (editable font source), `DarkGardenMK.afm`, `DarkGardenMK.pfb`, `DarkGarden-copying.txt`, `DarkGarden-copying-gpl.txt`, `DarkGarden-readme.txt` and `DarkGarden-changelog.txt`. DarkGarden is Copyright 1999, 2000, 2004 Michal Kosmulski, GPL-2.0-or-later with the document-embedding exception stated in its copying file. That exception concerns generated documents; the distributed font itself retains its license and source. These files accompany the runtime on both platforms; the Python package's BSD notice does not replace their terms.

PPT Master adds python-pptx 1.0.2, XlsxWriter 3.2.9, lxml 6.1.3, skia-pathops 0.9.2, uharfbuzz 0.56.1, PyYAML 6.0.3 and typing-extensions 4.16.0. Their original wheel license files remain in site-packages and are checked during preparation. The HarfBuzz and Microsoft USE notices missing from the uharfbuzz wheel are retained byte-for-byte in `notices/`, with source archive identity and content hashes in `manifest.json`; preparation copies them to each runtime's `office-notices` directory. The runtime receipt includes the manifest hash so notice changes invalidate older prepared runtimes.

lxml's wheels include statically linked GNU libiconv: 1.18 on macOS and 1.17.1 on Windows. Preserve its LGPL-2.1 text in `office-notices` as well as lxml's own LICENSE.txt and LICENSES.txt. The selected Windows wheel matches official build artifact 9843595966; job 100212452276 records digest-verified dependency archives from libxml2-win-binaries release 2026.05.17. The global build cache label is not the Windows iconv version. A notice alone does not complete distribution: the corresponding source/build material and a verified replacement/relink route must accompany public delivery. Those release checks remain open until their actual artifacts and receipts exist.

No Codex private runtime, artifact-tool, PyMuPDF, Hermes runtime or python-docx is included by these requirements. Word uses the existing TypeScript implementation. openpyxl does not calculate formulas or render spreadsheets; those acceptance gates remain separate.
